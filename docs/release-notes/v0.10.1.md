## What's new / 本次更新

**Markdown replies / 回复按 Markdown 排版**
- Headings, numbered and bulleted lists, tables, quotes, inline code and links render properly instead of
  showing `###` and `**` as text.
- Code blocks show the language and have a copy button; long commands scroll instead of wrapping.
- 标题、有序/无序列表、表格、引用、行内代码、链接都正常显示，不再出现 `###`、`**` 这类原始符号；
  代码块带语言标签和复制按钮，长命令横向滚动。

**Tool calls fold into steps / 工具调用折叠为步骤**
- A run of tool calls becomes one line, e.g. “执行了 7 步 · 运行命令”; open it to see each step with its
  status and command, and open a step to see its output. A call waiting for approval always stays visible.
- 连续的工具调用合并成一行“执行了 N 步”，展开后每步显示状态和命令，再展开可看输出；需要确认的调用始终显示。

**Also / 其他**
- The streaming caret follows the last line being written; the assistant panel opens wider by default.
- 流式光标跟随正在生成的最后一行；助手面板默认更宽。

The interface is in Simplified Chinese. / 界面为简体中文。
