## What's new / 本次更新

**One conversation per terminal tab / 每个终端标签一段对话**
- Switching tabs switches the assistant to that tab's conversation, and its commands only ever run on that tab's
  server. Before, a conversation started on one server could continue on another after a tab switch.
- A conversation from another host opened from history is read-only, with **到 X 继续** or **在这里开新对话**.
- 切换标签时助手切到该标签自己的对话，命令只在这个标签的服务器上执行。此前切换标签后，对话可能在另一台服务器上继续执行。
- 从历史打开另一台主机的对话时只读，可选「到 X 继续」或「在这里开新对话」。

**Long conversations fit the model / 长对话按模型自动控制**
- Nothing is cut until a conversation nears the model's context size, so provider caching keeps working. The size is
  read from the provider's model list where it states one, or learned from its "too long" error, remembered, and the
  request is shortened and retried automatically. A manual size is optional in the provider settings.
- 平时不精简，服务商的缓存照常生效；接近上限时才从最早的命令输出开始精简。上限能从模型列表读到就直接用，
  读不到时从服务商的超长报错里得知并记住，然后自动精简重试；服务商设置里可选手动设置。

**Stop a reply / 随时停止回复**
- The send button becomes **停止** while the assistant works. Closing a tab or locking stops its reply too — before,
  closing a tab whose command was waiting for approval left the assistant stuck in every tab until restart.
- 回复进行中发送按钮变成「停止」；关闭标签或锁定也会自动停止。此前关闭一个正在等待确认的标签，会让所有标签的助手卡住直到重启。

The interface is in Simplified Chinese. / 界面为简体中文。
