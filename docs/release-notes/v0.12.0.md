## What's new / 本次更新

**The assistant types into the terminal / AI 助手在终端里输入命令**
- The assistant can now type a command into the terminal you are looking at, the way you would, and read the answer
  once the device is back at its prompt. Switches that refuse a separate command channel, configuration views such
  as `system-view` and interface views, and `---- More ----` pages all work: pages are turned for you, and the
  assistant is told which view it ended up in.
- 助手现在可以把命令直接输入到你正在看的终端里，和你自己打字一样，等设备回到提示符后读取结果。
  不支持独立命令通道的交换机、`system-view` 和接口视图这类配置视图、`---- More ----` 分页都能正常处理：
  分页会自动翻，助手也会知道自己当前在哪个视图里。
- Works in SSH, Telnet, serial and local terminal tabs. Telnet, serial and local tabs offer only the terminal tools,
  since they have no file access.
- SSH、Telnet、串口、本地终端标签都可以用。Telnet、串口和本地终端没有文件访问，所以这几类标签里助手只能操作终端。

**Safety / 安全**
- Every command is shown for your approval before it is typed. While the assistant types, a banner over the terminal
  says so, your keyboard input is paused, and **停止** interrupts the command.
- A password or `[Y/N]` question hands control back to you; the assistant can press only a fixed set of keys
  (Ctrl+C, Enter, space, q, y, n) and can never type a password.
- Commands that reboot, erase or format (`reboot`, `reset saved-configuration`, `delete`, `rm -rf` and similar)
  always ask, even in full-auto mode, and are marked in red.
- 每条命令在输入前都会先给你确认。助手输入期间，终端顶部会有横幅提示，你的键盘输入暂停，点 **停止** 可以中断命令。
- 遇到密码或 `[Y/N]` 提问时交还给你；助手只能按固定的几个键（Ctrl+C、回车、空格、q、y、n），没有办法输入密码。
- 重启、清除配置、格式化这类命令（`reboot`、`reset saved-configuration`、`delete`、`rm -rf` 等）
  即使在“完全放开”模式下也必须确认，并用红色标出。

**Fixes / 其他修复**
- An approved step now shows as running at once, instead of keeping its 允许 / 拒绝 buttons until it finished.
- `read_terminal` now reads the screen as it is, not as it was when the question was asked.
- 批准后的步骤会立即显示为“执行中”，不再一直显示“允许 / 拒绝”按钮直到执行结束。
- 助手读终端时读到的是当前屏幕，而不是提问那一刻的快照。

The interface is in Simplified Chinese. / 界面为简体中文。
