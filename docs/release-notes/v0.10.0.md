## What's new / 本次更新

**Streaming AI replies / AI 回复流式输出**
- Replies appear as the model writes them, for OpenAI-compatible, OpenAI Responses and Anthropic providers.
- Tool calls now sit inline where they happened — text, then the command it ran, then the rest of the answer —
  instead of the answer on top and every tool call underneath.
- 三种接口的回复都会边生成边显示；工具调用按发生顺序穿插在回答中，不再是答案在上、执行过程全堆在下面。

**Terminal colour schemes / 终端配色**
- 10 schemes under 设置 → 终端 → 配色: loki, One Dark, Dracula, Nord, Tokyo Night, Catppuccin Mocha,
  Gruvbox Dark, Solarized Dark / Light, GitHub Light. Applied live to open terminals.
- 设置 → 终端 → 配色 提供 10 套方案，切换后已打开的终端立即生效。

**Recovery code export / 恢复码导出**
- The one-time recovery code shown at setup can be copied or saved to a text file.
- 创建保险库时显示的恢复码现在可以复制，或保存为文本文件。

**New icon / 新图标**
- A new white app icon. / 全新的白色应用图标。

The interface is in Simplified Chinese. / 界面为简体中文。
