## What's new / 本次更新

**Quick connect: SSH, Telnet, serial, local / 快速连接可选协议**
- The **+** on the tab bar (and ⌘T / Ctrl+Shift+T) now has a protocol switch. Telnet takes `host:port`;
  serial lists the detected devices with baud rate, data bits, parity and stop bits. No saved host needed,
  reconnect works, and **保存为主机** in the tab menu turns it into a host.
- 标签栏 **+**（以及 ⌘T / Ctrl+Shift+T）可选协议：Telnet 输入 `host:port`；串口列出检测到的设备，可选波特率、
  数据位、校验、停止位。不用先建主机，断开后可重新连接，标签右键「保存为主机」即可保存。

**Export and record terminal output / 终端导出与会话录制**
- **更多** in the tab bar: export the terminal's contents, export the selection, or start recording.
  A recording is written as the output arrives, so a long `show running-config` is kept in full even past
  the scrollback limit. Plain-text mode strips colours and cleans up pager prompts such as `--More--`.
  It stops on its own when the tab closes or the vault locks.
- 标签栏 **更多** 菜单：导出终端内容、导出选中内容、开始录制。录制在输出到达时直接写入文件，
  长配置超出回滚行数也完整保留；纯文本模式去掉颜色控制符，`--More--` 这类分页提示不会残留。
  关闭标签或锁定时自动停止。

**AI conversation history / AI 历史对话**
- Conversations are saved per host, encrypted in the vault, and never synced. Open **历史对话** to continue,
  rename or delete one; **+** starts a new one.
- 对话按主机加密保存在本机保险库，不参与同步。点 **历史对话** 可继续、重命名、删除；**+** 开始新对话。

**Attach files for the assistant / 给 AI 附加文件**
- The paperclip (or dragging files onto the assistant) uploads them to `~/.loki/uploads/…` on the current
  SSH server, with private permissions and a hash check, and shows real upload progress. The assistant then
  uses them with its usual tools — e.g. "install this certificate on nginx" — and changes still need your
  approval. Private key contents are never sent to the model, and key blocks are hidden from all tool output.
  The **发给 AI** item in the files panel sends a remote path to the assistant.
- 回形针（或把文件拖到助手面板）会把文件上传到当前 SSH 服务器的 `~/.loki/uploads/…`，权限私有并校验哈希，
  显示真实上传进度。AI 用现有工具完成后续操作（比如「把这个证书装到 nginx 上」），改动服务器仍需你确认。
  私钥内容永远不发给模型，所有工具输出里的私钥块都会被隐藏。文件面板右键「发给 AI」可把远端路径交给助手。
