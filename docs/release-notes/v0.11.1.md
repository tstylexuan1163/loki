## What's new / 本次更新

**Password prompt / 密码弹窗**
- A password typed at the prompt is now used even when the host already has a stored one.
- Show what you typed with the eye button; warnings for Caps Lock and for full-width characters from a
  Chinese input method; the server's actual reason is shown when it is not simply a wrong password.
- 弹窗里输入的密码现在会优先使用，即使主机里已经存过旧密码。
- 可点眼睛图标查看输入内容；大写锁定、输入法处于中文状态（全角字符）时会提示；
  服务器拒绝的原因不是“密码错误”时显示真实原因。

**Username is optional / 用户名可以不填**
- Hosts can be saved without a username. Connecting asks for one and can save it to the host after a
  successful login.
- 主机可以不填用户名保存，连接时会询问，登录成功后可保存到主机。

**Smoother pop-ups on Windows / Windows 弹出层更流畅**
- Menus, dialogs and prompts no longer use background blur or slide animations on Windows, which could
  make clicks stutter and leave trails.
- Windows 上菜单、对话框、提示不再使用背景模糊和位移动画，减少点击卡顿和残影。

The interface is in Simplified Chinese. / 界面为简体中文。
