## What's new / 本次更新

**AI providers now take any endpoint / AI 服务商可接任意端点**
- OpenAI-compatible (OpenAI, OpenRouter, DeepSeek, Ollama, LM Studio, vLLM…), Anthropic Messages, and OpenAI Responses.
- Base URL carries the API version; models are a list per provider, with "fetch model list" and "test connection".
- A blank API key sends no auth header, so local servers work.
- 支持 OpenAI 兼容（含 OpenRouter、DeepSeek、Ollama、LM Studio、vLLM 等）、Anthropic、OpenAI Responses；
  基础地址带 API 版本；每个服务商可加多个模型，支持「获取模型列表」和「测试连接」；密钥留空则不发送认证头。

**Updates are checked and installed in the app / 应用内检查并安装更新**
- Checks on launch and from Settings → About; a non-modal prompt shows the version and notes.
- Downloads, **verifies the signature**, then hands off to the platform installer.
- Signature verification is mandatory: an unsigned or tampered package is rejected and nothing is installed.
- 启动时和「设置 → 关于」可检查；有新版在右下角提示，点一下即可下载安装；
  强制校验签名，未签名或被篡改的包一律拒绝。

**Windows title bar fixed / Windows 标题栏修复**
- The window is now frameless on Windows with in-app minimise / maximise / close buttons — no more double title bar.
- The installer picks Chinese or English from the system language, falling back to Chinese.
- Windows 改为无边框窗口并自绘窗口按钮，不再出现两条标题栏；安装界面按系统语言自动选择（中文优先兜底）。

**Everything from 0.7 / 0.7 的功能都在**
- SSH, Telnet, serial and local terminals in tabs, with find and a live server status bar.
- Host keys trusted on first use and stored encrypted; a changed key is flagged.
- Key → key vault → ssh-agent → password, with a prompt; jump hosts; quick connect (⌘K / Ctrl+Shift+K).
- SFTP panel with file and folder transfer, drag-and-drop, and an editor.
- Key generation and import, `~/.ssh/config` import, local and SOCKS5 forwarding.
- Everything stored as AES-256-GCM ciphertext under an Argon2id-derived key; a one-time recovery code.
- 多协议终端标签（SSH / Telnet / 串口 / 本地）、服务器状态栏、主机密钥首次确认后加密保存、
  认证链与跳板机、快速连接、SFTP 上传下载、密钥生成与导入、端口转发、恢复码、全库密文。

The interface is in Simplified Chinese. / 界面为简体中文。

## Upgrading / 升级

From 0.9.0 onward the app can update itself: **设置 → 关于 → 检查更新**.
Earlier versions must be replaced manually once.

从 0.9.0 起可以在应用内升级（设置 → 关于 → 检查更新）；更早的版本需要手动替换一次。
