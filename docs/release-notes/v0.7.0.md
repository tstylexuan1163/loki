The installers are **not code-signed**. macOS: if the app is reported as damaged, run
`xattr -dr com.apple.quarantine /Applications/loki.app`. Windows: SmartScreen → **More info** → **Run anyway**.

安装包**暂未签名**。macOS 提示“已损坏”时执行 `xattr -dr com.apple.quarantine /Applications/loki.app`；
Windows 在 SmartScreen 提示里点 **更多信息** → **仍要运行**。

## Highlights / 主要内容

- SSH, Telnet, serial and local terminals in tabs, with find and a server status bar
  多协议终端标签（SSH / Telnet / 串口 / 本地），终端内查找，服务器状态栏
- Host keys trusted on first use and stored encrypted; a changed key is flagged
  主机密钥首次确认后加密保存，密钥变化时告警
- Key → key vault → ssh-agent → password, with a password prompt; jump hosts; quick connect
  私钥 → 密钥库 → ssh-agent → 密码依次尝试并可弹框输入；跳板机；快速连接
- SFTP panel with file and folder upload/download, drag-and-drop, and an editor
  SFTP 面板：文件/文件夹上传下载、拖拽上传、内置编辑器
- AI assistant (OpenAI-compatible or Anthropic) that can read the terminal and run tools with your approval
  AI 助手（OpenAI 兼容或 Anthropic），读取终端、在你确认后调用工具
- Key generation and import, `~/.ssh/config` import, local and SOCKS5 forwarding
  密钥生成与导入、`~/.ssh/config` 导入、本地与 SOCKS5 端口转发
- Everything is stored as AES-256-GCM ciphertext under an Argon2id-derived key
  所有数据以 Argon2id 派生密钥下的 AES-256-GCM 密文保存

The interface is in Simplified Chinese. / 界面为简体中文。
