## What's new / 本次更新

**Scan a subnet / 扫描网段**
- **主机 → 扫描网段**: enter a range such as `10.0.8.0/24` or `10.0.8.1-50`, and loki finds every device with SSH or
  Telnet open, names the vendor from its greeting (H3C, Huawei, Ruijie, ZTE, Cisco and more), and adds the ones you
  tick in one go, with a shared login, a name template such as `{vendor}-{ip}`, and categories. Devices already
  saved are marked and skipped.
- 在「主机 → 扫描网段」输入 `10.0.8.0/24` 或 `10.0.8.1-50`，loki 会找出开放 SSH 或 Telnet 的设备，
  根据设备打的招呼识别厂商（H3C、华为、锐捷、中兴、思科等），勾选后一次添加，可以统一设置登录账号、
  命名模板（如 `{vendor}-{ip}`）和分类；已经保存过的设备会被标出并跳过。

**Telnet / Telnet**
- Typing no longer lags: every keystroke used to wait up to a quarter second behind the screen reader.
- Switches now learn the window width, so long lines are no longer wrapped at 80 columns.
- No more stray characters from split protocol commands, and no more lost characters after keepalives.
- 打字不再卡顿：此前每个按键都可能被延迟到 1/4 秒。
- 交换机现在能拿到窗口宽度，长配置不再在 80 列处折行。
- 不再出现协商命令被拆开时漏出的乱码，也不会在设备发保活命令后丢字符。

**Signing in / 登录**
- First connection to a new server via quick connect no longer loops between the fingerprint and password prompts.
- Quick connect with just an address asks for the login name instead of trying `root`.
- "Remember password" on a jump host's prompt now saves it on the jump host, not the target.
- 首次快速连接新服务器时，不再在“确认指纹”和“输入密码”之间来回循环。
- 快速连接只输入地址时会询问用户名，不再默认用 `root`。
- 跳板机密码提示里勾选“记住密码”，现在会存到跳板机上，而不是目标主机。

**Fixes / 其他修复**
- Stopping a port forward frees the port at once, so it can be started again right away.
- An unplugged serial adapter now shows the tab as closed.
- Windows: typing `exit` in a local terminal now closes the session.
- Downloads always stay inside the chosen folder, whatever names the server sends.
- 停止端口转发后立即释放端口，可以马上重新建立。
- USB 串口线被拔掉后，标签页会显示为已关闭。
- Windows：本地终端里输入 `exit` 后会正常结束会话。
- 下载的文件始终保存在你选择的文件夹里，无论服务器返回什么文件名。
